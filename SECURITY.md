# Security policy

## Supported versions

Only the latest stable release of each `@mapples/*` package on npm receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue:

1. Use **Report a vulnerability** on the [Security tab](https://github.com/mapplesorg/mapples-open-kit/security) of this
   repository (GitHub private vulnerability reporting), or
2. email **support@mapples.org** with "Security" in the subject.

Include the affected package and version, a description of the issue, and steps to reproduce. We aim to acknowledge a
report within 3 business days and will keep you updated until a fix is published.
