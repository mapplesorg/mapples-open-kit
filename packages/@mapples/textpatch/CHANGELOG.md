## 2.0.0

### Major Changes

- cffb0d6: Mapples 2.0: every `@mapples/*` and `@mapplesorg/*` package is released as 2.0.0, together with the `mapples` CLI 2.0.0. Apps generated by the CLI depend on `@mapples/*` `^2.0.0`.

### Minor Changes

- b6d3791: Source text as git-style hunks (RFC-0001 A13). New `@mapples/textpatch`: unified-diff hunks for a file's text — `makeHunks`, an exact `applyHunks` mirrored line for line by the server's Python applier, `merge3` (line-level 3-way, no markers), `textHash` — shared by the Creator and the `mapples` CLI. `@mapplesorg/jpatch` gains the `text: {base, hunks}` update directive on `Source` (the tree applies it with base verification; `patch.text` is refused), the `SOURCE_BASE_MISMATCH` / `SOURCE_PATCH_INVALID` codes, and code-aware summaries (`Edited code of “Home” (+12 −3)` via `namesFromTree`). The Creator's outbox sends a Save as hunks against the optimistic text, coalesces repeated Saves of one file, and rebases a queued directive over a peer's edit with a 3-way merge — overlapping lines surface as a casualty instead of a silent overwrite. `@mapplesorg/api` gains `Network.Core.Canvas.historyCommit` (`GET …/canvas/history/{seq}`), and the History panel expands a commit into its changes with the hunks of every code edit.
