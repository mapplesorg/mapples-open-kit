## 1.0.0

### Major Changes

- b5ae001: 🎉 **Initial Release - Mapples Open Kit v1.0.0**

  We're excited to announce the first official release of Mapples Open Kit! This comprehensive React Native toolkit provides developers with a powerful set of components and utilities to build modern, scalable mobile applications.

  ## What's Included

  This initial release includes 8 core packages:
  - **@mapples/action** - Action management and state handling
  - **@mapples/dnd** - Drag and drop functionality
  - **@mapples/form** - Form management and validation
  - **@mapples/render** - Rendering utilities and components
  - **@mapples/state** - State management solutions
  - **@mapples/style** - Styling system and theming
  - **@mapples/types** - TypeScript type definitions
  - **@mapples/ui** - UI component library

  ## Key Features

  ✨ **Modern React Native Development** - Built with the latest React Native and Expo technologies
  🎨 **Comprehensive UI Components** - Ready-to-use components with consistent design
  📱 **Cross-Platform Support** - Works seamlessly on iOS and Android
  🔧 **Developer Experience** - TypeScript support, comprehensive documentation, and easy integration
  🏗️ **Modular Architecture** - Use only what you need with our modular package structure

  ## Getting Started

  Install the packages you need:

  ```bash
  yarn add @mapples/ui @mapples/form @mapples/state
  ```

  This is just the beginning! We're committed to continuously improving and expanding the Mapples Open Kit ecosystem. Stay tuned for more features, components, and improvements in future releases.

  Happy coding! 🚀
