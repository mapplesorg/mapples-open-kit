## 2.0.0

### Major Changes

- cffb0d6: Mapples 2.0: every `@mapples/*` and `@mapplesorg/*` package is released as 2.0.0, together with the `mapples` CLI 2.0.0. Apps generated by the CLI depend on `@mapples/*` `^2.0.0`.

### Minor Changes

- 145e7d3: New package: turns cURL commands, OpenAPI 3 / Swagger 2 documents (JSON or YAML) and Postman collections (v2.0/v2.1) into Mapples API requests, and `mergeApiImport` folds them into a project API document (`rename` or idempotent `replace` on name clashes). Pure and runtime-neutral (Node ESM): the Creator's import dialog and the `mapples` CLI share it. Credentials are never imported — only the secret names to store them under; a collection's credential is never inherited by requests to another origin; a relative OpenAPI server URL resolves against `sourceUrl` or throws.

### Patch Changes

- d19ef84: Internal `dependencies` (not peers) between `@mapples/*` and `@mapplesorg/*` packages are pinned to the exact version of the same release train, so a fresh `npm install` of a beta can no longer resolve a sibling to the `rc` build (which sorts above every beta of the same version) — `@mapples/codegen` beta no longer pulls an `@mapples/sid-ast` rc missing `isPropBinding`.
