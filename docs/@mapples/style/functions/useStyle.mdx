# Function: useStyle()

> **useStyle**(`customStyleConfig?`): [`StyleContextType`](../interfaces/StyleContextType.mdx)

Defined in: [hooks/useStyle.ts:38](https://github.com/mapplesorg/mapples-open-kit/blob/48ed65f45ba920a5d5b2f05f069ea0a621919a37/packages/@mapples/style/src/hooks/useStyle.ts#L38)

Hook to access the current style configuration from the StyleContext.

## Parameters

### customStyleConfig?

[`StyleContextType`](../interfaces/StyleContextType.mdx)

Optional custom style configuration to override the context value

## Returns

[`StyleContextType`](../interfaces/StyleContextType.mdx)

The style configuration object containing theme, typography, sizing, and responsive settings

## Examples

```tsx
const MyComponent = () => {
  const style = useStyle();

  return (
    <View style={{ backgroundColor: style.themeConfig.light.primary }}>
      <Text>Styled content</Text>
    </View>
  );
};
```

```tsx
const MyComponent = () => {
  const customStyle = {
    themeConfig: { / custom theme / },
    typographyConfig: { / custom typography / }
  };
  const style = useStyle(customStyle);

  return <Text>Using custom style</Text>;
};
```
