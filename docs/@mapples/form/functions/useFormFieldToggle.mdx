# Function: useFormFieldToggle()

Defined in: [hooks/useFormFieldToggle.ts:32](https://github.com/mapplesorg/mapples-open-kit/blob/9e75d5ea841ea5751ed3fc9e83874977d4f7794b/packages/@mapples/form/src/hooks/useFormFieldToggle.ts#L32)

Hook to manage boolean toggle fields.
This hook provides a simple way to handle boolean fields with toggle functionality.

## Parameters

### fieldPath

`string`

Dot notation path to the boolean field

## Returns

`object`

Object containing current value and toggle function

### value

> **value**: `boolean`

### toggleValue()

> **toggleValue**: () => `void` = `handleToggleValue`

#### Returns

`void`

## Example

```tsx
const ToggleField = () => {
  const { value, toggleValue } = useFormFieldToggle('isActive');

  return (
    <label>
      <input
        type="checkbox"
        checked={value}
        onChange={toggleValue}
      />
      Active
    </label>
  );
};
```
