# Function: useFormContext()

> **useFormContext**(): [`FormContextType`](../interfaces/FormContextType.mdx)\<`object`\>

Defined in: [hooks/useFormContext.ts:30](https://github.com/mapplesorg/mapples-open-kit/blob/2cf247e3716d7da57d20142515c42c35223f2b70/packages/@mapples/form/src/hooks/useFormContext.ts#L30)

Hook to access the form context containing form state and methods.
This hook provides access to the FormState instance, validation errors,
submission state, and form control methods.

## Returns

[`FormContextType`](../interfaces/FormContextType.mdx)\<`object`\>

Form context object with form state and methods

## Example

```tsx
const MyComponent = () => {
  const { form, submitting, submitForm, validationErrors } = useFormContext();

  return (
    <div>
      <button onClick={submitForm} disabled={submitting}>
        {submitting ? 'Submitting...' : 'Submit'}
      </button>
      {validationErrors && <div>Validation errors occurred</div>}
    </div>
  );
};
```
